# DUAL-ASCENT — Independent Research Package, Revision Three

## Commission outcome

**Recommendation: REVISE.** DUAL-ASCENT should remain documentation-first until an ethics-appropriate manual pilot shows a specific reproducibility or governance need that a notebook/spreadsheet cannot meet. Revision-three source corrections and synthetic tests do not demonstrate human learning, agency, creativity, calibrated reliance, prospective-intention validity, or production readiness.

## Evidence-status legend

| Label | Meaning |
|---|---|
| EXECUTED | A local synthetic-code, gate, or archive command actually ran in the third-pass environment; see `VALIDATION_REPORT.md`. |
| STATICALLY REVIEWED | Source/archive/document/workflow content was inspected without asserting broader runtime/security evidence. |
| PROPOSED | Design, protocol, or future capability not implemented by the reference utility. |
| NOT TESTED | Requires another runtime, independent review, or approved human-subject research. |

## Separate proposed implementation artifact

`DUAL_ASCENT_PROPOSED_IMPLEMENTATION_rev3.zip` is separately delivered clean reference source. It contains proposed local utility code, synthetic fixtures, golden vectors, tests, proposed CI, usage instructions, and Apache-2.0 license. It is not a code contribution to the public repository, does not collect data, and is excluded from the documentation-only PR.

The standalone `sha256sums.txt` remains outside both revision-three ZIPs and lists only their final SHA-256 values. It witnesses matching delivered bytes, not research truth or execution outside the documented environment.
